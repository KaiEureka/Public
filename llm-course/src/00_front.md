# 前言 {#preface .front}

这本书整理自一门一对一的课程。学员在开课时提出了一个目标：

> 假设穿越回 2017 年之前，手里有充足的资金，能否**只凭脑中的知识**，复现出今天的前沿大模型？

要做到这一点，就不能只懂"模型结构"这一个环节，而要了解一家训练大模型的公司里**每一个岗位都在做什么**：数据怎样采集和清洗，集群怎样搭建，几万张卡怎样协同训练几个月不出事，预训练好的模型怎样变成会推理、会用工具的助手，怎样评测，怎样保证安全，怎样以合理的成本提供服务，公司又怎样运转。课程正是按照这个"全栈"的思路设计的。

课程分两步走。**第一步**（第 0–36 章）：从"其实并不会这些知识"出发，学会**今天**训练前沿大模型所需的全部知识。**第二步**（第 37–39 章）：在掌握这些知识之后，讨论穿越回 2017 年时，在当时的硬件、软件和数据条件下怎样完成复现，以及需要注意什么。

### 读者与前置知识

本书面向熟悉 Python、写过一些 PyTorch、具备计算机专业本科数学基础（微积分、线性代数、概率）的读者。凡是第一次出现的术语，都会先给出定义再使用；用到前面章节的结论时，会注明章号。

### 本书的结构

全书分九篇、四十章，外加五个附录。每一章都按同样的结构组织：

- **学习目标**：读完这一章应该能做到什么；
- **正文**：从问题出发，先讲动机，再推导原理，然后给出实现或实验，最后介绍业界今天的做法；
- **本章要点**：用几条话概括全章；
- **习题**：计算、推导、思考和设计题。参考答案见附录 D，其中设计题和开放题只给要点，部分从略。

### 三类数字

书中的数字分为三类，阅读时请注意区分：

| 类别 | 含义 | 标注方式 |
|--------|------------------------------|--------------|
| **实测** | 在课程环境中实际运行得到。环境是一台 4 核 CPU 的云端虚拟机，模型都很小，用来说明规律，而不是追求绝对性能 | 放在"实验（实测）"框中 |
| **引用** | 来自已发表的论文、技术报告或厂商资料 | 注明作者与年份或机构，参考文献见附录 E |
| **示意 / 估算** | 为了说明概念而构造的例子，或者用书中公式做的数量级估算 | 注明"示意"或"估算" |

涉及公司财务、未公开的工程细节和法律问题时，书中只给出公开报道中的信息或数量级判断，不应当作精确事实或专业意见。

# 整理说明 {#revision .front}

本书以课堂上讲过的内容为主体。整理时，从全书的角度通读了所有讲稿，做了以下调整，目的是让它更适合作为一本教材来使用。

::: revision
1. **结构统一。** 全书整理为九篇四十章，每章统一为"学习目标 → 正文 → 本章要点 → 习题"的结构；每篇开头增加一页导读，说明本篇各章之间的关系。删去了课堂上的对话性语句和课程安排方面的说明。
2. **第 0 章只讲今天的知识。** 第一次授课时，第 0 章混入了"2017 年有什么硬件、要花多少钱"等穿越内容，顺序放反了。本书把这部分全部移到第九篇（第 37–39 章），第 0 章只保留项目的生命周期、团队分工和核心账本，习题也改为以 H100 为准。
3. **把课堂答疑写进正文。** 学员曾追问"一串文本的概率，到底是什么事件的概率"。这个问题问到了语言模型定义的要害，本书把相应的回答整理为第 1 章的 1.2 节，并更正了原讲稿中链式分解遗漏结束符 ⟨eos⟩ 的问题。第 1 章的 1.5–1.6 节采用了课堂上按"先定义、后使用"原则重写过的版本。
4. **统一符号。** 隐藏维度一律记为 $d$，序列长度一律记为 $T$（第 20、21 章的讲稿中原来分别用 $h$ 和 $s$）。采样、蒸馏和对比学习中的温度一律记为 $\tau$，避免与序列长度混淆。参与切分或通信的卡数记为 $n$，避免与参数量 $N$ 混淆。完整的符号表见下一节。
5. **规范实验和数字的呈现方式。** 所有实测结果都放进"实验（实测）"框，并注明设置；示意性的数字一律标注"示意"；引用的数字尽量注明出处。
6. **修正与补充。** 修正了通读时发现的笔误和不够准确的表述。例如：第 5 章原讲稿说中文的 API 费用"约为英文的 3 倍"，但实验比较的是同一段中文在两种分词器下的 token 数，本书改为与实测一致的"约 2.6 倍"；第 9 章把"约 19 对维度"精确为"18 对超过训练长度、1 对与之相当"；第 29 章表格中反向 KL 的写法有误，已更正；第 35 章的扩散步数改记为 $K$，避免与序列长度 $T$ 混淆。原第 0 课结尾的开放题"前 90 天做哪五件事"移到第 37 章习题 7，读完第 39 章的路线图之后再对照。在不改变原意的前提下，还补充了少量推导步骤和交叉引用。
7. **新增附录。** 附录 A 是术语表，附录 B 是关键数字与公式速查，附录 C 是实验与代码索引，附录 D 是部分习题的参考答案，附录 E 是参考文献。
8. **增加插图。** 在讲稿原有的 8 张图之外，新增了 169 张示意图和数据图，全书共 177 张编号的图，每章 1 到 8 张，正文中都标明了"见图 x.y"。数据图都在图注或图中注明来源：画实验结果的标"实测"，数字与对应的实验表格一致，由书中的程序得出（例如第 35 章的去噪过程图，是把 35.5 节的实验复跑一遍、记下中间各步的采样点画出的）；按公式算出的标"估算"；只为说明原理、数字并非测量所得的标"示意"。流程图、结构图等不含数据的图不再逐一标注。所有插图都由 `figs/` 目录中的程序生成，可以重新绘制。
:::

### 约定

- **FLOP 与 FLOP/s**：FLOP 表示运算次数，FLOP/s 表示每秒运算次数。很多资料把两者都写作 FLOPS，阅读时请留意。
- **数量级**：K = 10³，M = 10⁶，B = 10⁹，T = 10¹²，P = 10¹⁵。参数量和 token 数常用 B 和 T 表示，比如 70B 参数、15T token。
- **带宽**：如无特别说明，指**单方向**带宽。双向合计的数字会注明"双向"。
- **"token"、"loss"、"batch"、"logits"、"embedding"、"KV cache"、"prefill"、"decode"** 等术语保留英文原词，含义见附录 A。
- **"实测""引用""示意"** 三类数字的含义见前言。
