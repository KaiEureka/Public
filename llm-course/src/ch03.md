### 3.1 初始化

#### 两路信号都不能失控

先定义一个词：**激活值**是每一层的输出。训练时有两路信号在网络里流动：

- **前向**：激活值从输入层一层层传到输出层；
- **反向**：梯度从 loss 一层层传回输入层。

如果每经过一层信号就放大一点，比如 ×1.5，20 层之后就会放大约 3,300 倍，这叫**爆炸**。如果每层缩小一点，比如 ×0.7，20 层之后就只剩约千分之一，这叫**消失**。初始化的任务，就是让这两路信号在训练刚开始时，每过一层都大致保持原来的尺度。

#### 推导：权重该取多大

一个线性层的单个输出是 $a = \sum_{i=1}^{n} x_i w_i$，对 $n$ 个输入求和。$n$ 叫这一层的 **fan_in**，即输入的个数。假设 $x$ 和 $w$ 相互独立、均值都为 0，那么

$$
\operatorname{Var}(a) = n\cdot\operatorname{Var}(w)\cdot\operatorname{Var}(x).
$$

要让 $\operatorname{Var}(a) = \operatorname{Var}(x)$，就需要 $\operatorname{Var}(w) = 1/n$，即**权重的标准差取 $1/\sqrt{n}$**。这叫 Xavier 初始化（或 LeCun 初始化）。

接下来要考虑激活函数的影响：

- **tanh** 在输入很小时近似于 $y = x$，输入很大时被压在 $\pm1$ 附近。被压住的状态叫**饱和**，此时导数几乎为 0，梯度传不过去。tanh 平均来说会把方差压小一点，所以要乘一个**增益**（gain）来补偿，PyTorch 推荐的值是 $5/3$。这就是第 2 章代码中 ×5/3 的来历。
- **ReLU** 是另一种最常用的激活函数，定义为 $\max(0, x)$。它会把一半的输入直接变成 0，方差减半，所以增益是 $\sqrt{2}$，对应的标准差是 $\sqrt{2/n}$。这叫 Kaiming 初始化（或 He 初始化）。

::: experiment
**实验 1：一个 20 层网络刚初始化时的状态。** 网络有 20 层，每层宽 128，使用 tanh 激活。不训练，只做一次前向和一次反向，测量各层的信号。"梯度大小"指各层权重梯度的均方根。

| 初始化 | 激活值的标准差（第 1/5/10/20 层） | 饱和比例（$\lvert h\rvert > 0.97$） | 梯度大小：第 20 层 → 第 1 层 |
|---|---|---|---|
| std = 1 | 0.96 / 0.96 / 0.96 / 0.96 | **85%** | 1.9e-5 → **6.2e+2**（放大约 3,000 万倍） |
| std = $1/\sqrt{n}$ | 0.61 / 0.32 / 0.22 / **0.16** | 约 0% | 1.9e-5 → 5.2e-6（逐层变小） |
| std = $(5/3)/\sqrt{n}$ | 0.74 / 0.65 / 0.65 / 0.65 | 约 5% | 1.9e-5 → 1.1e-4（差距在 6 倍以内） |
:::

逐行解读（{{fig-ch03-signal}}）：

- **std = 1**：每层的输入是 128 个数的加权和，标准差约为 $\sqrt{128} \approx 11$，远远超出 tanh 的线性区，85% 的单元都饱和了。激活值的标准差是 0.96，是因为这些值几乎都钉在 $\pm1$ 上。反向传播时，每往回一层都要乘以 $W^\top$（尺度约为 11），饱和只抵消了其中一部分，所以梯度一路**爆炸**。
- **std = $1/\sqrt{n}$**：线性部分刚好保持方差不变，但 tanh 每层都把信号压小一点，又没有补偿，激活值从 0.61 一路衰减到 0.16，梯度也在逐层变小，这是**消失**。20 层时还不算严重，层数再多就会很明显。
- **std = $(5/3)/\sqrt{n}$**：信号基本稳定。

#### 输出层要特别"谦虚"：×0.01 的来历

输出层计算 $\text{logits} = hW_{\text{out}}$。如果 $W_{\text{out}}$ 的初始值偏大，模型一开始就会对随机的答案非常自信。第 1 章说过，交叉熵会重罚"自信地猜错"。

::: experiment
**实验 3：输出层的初始尺度。** 一个隐藏层的网络，宽 512，用 SGD（学习率 0.1）训练，只改变 $W_{\text{out}}$ 的初始标准差：

| $W_{\text{out}}$ 的标准差 | 初始 loss | 200 步 | 2,000 步 |
|---|---|---|---|
| **0.01** | **4.196**（$\ln 65 = 4.174$） | 2.715 | 2.311 |
| $1/\sqrt{512} \approx 0.044$ | 4.485 | 2.749 | 2.315 |
| 1.0 | **40.975** | 7.383 | 2.919 |
:::

标准差为 1 时，初始 loss 高达 41，前几百步都花在"纠正过度自信"上，2,000 步之后仍然落后很多。所以有一条原则：**初始化时让输出接近均匀分布，使初始 loss 约等于 $\ln V$。** 这也是第 1 章说"初始 loss 应约等于 $\ln V$"的原因：它可以用来检查初始化是否正常。

**业界的实际做法**：GPT-2 把所有权重初始化为均值 0、标准差 0.02 的正态分布，并把每个残差分支（3.2 节解释）的输出层再按 $1/\sqrt{\text{残差分支数}}$ 缩小。现代模型大多沿用类似的小标准差，或者使用随模型规模调整的方案，比如 μP（第 11 章）。

### 3.2 把网络叠深：残差连接与归一化

#### 好的初始化还不够

初始化只能保证训练开始那一刻信号稳定。训练过程中权重不断变化，各层的信号尺度也会跟着漂移。另外，普通网络的每一层都必须自己学会"把有用的信息完整地传下去"。2015 年 ResNet 的论文（He 等）发现，普通网络加深到几十层后，**连训练集上的误差都比浅层网络更高**，这叫**退化问题**。

#### 残差连接

**残差连接**把每一层的计算方式从"替换"改成了"修正"：

$$
\text{普通层：}\; h_{l+1} = f(h_l), \qquad \text{残差层：}\; h_{l+1} = h_l + f(h_l).
$$

残差层中，每一层只负责在原有基础上加一个修正量 $f(h_l)$，这一项叫**残差分支**。看反向传播：

$$
\frac{\partial h_{l+1}}{\partial h_l} = I + \frac{\partial f}{\partial h_l},
$$

其中 $I$ 是单位矩阵。无论 $f$ 那一项多小，或者乱成什么样，**总有一个 $I$ 能把梯度原封不动地传回去**。这样，顶层的梯度可以沿着"恒等路径"直达任何一层，可以把它想成一条梯度高速公路。另外，初始化时如果 $f$ 很小，整个网络近似于恒等映射，起点非常平稳。

**残差流**：从这个角度看，$h$ 就像一块所有层共享的"工作台"，每一层从上面读取信息，再把自己的计算结果加回去。Transformer 就是按这种思路搭建的（第 6 章）。

#### 归一化

残差连接会带来一个新问题：每一层都往 $h$ 上加东西，$h$ 会越来越大。在实验 1 的网络中加上残差连接后，残差流的标准差从第 1 层的 1.2 增长到第 20 层的 3.5。而且训练过程中，每一层输入的尺度也会漂移。

**归一化**的做法是：在把向量送进某一层之前，先把它缩放到标准尺度。对一个样本的 $d$ 维向量 $x$：

| 方法 | 公式 | 说明 |
|---|---|---|
| **LayerNorm** | $y = \gamma\odot\dfrac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$ | $\mu$ 和 $\sigma^2$ 是这个向量自身的均值和方差。$\gamma$、$\beta$ 是可学习的参数，让模型在需要时恢复尺度。$\epsilon$ 是防止除以 0 的小数 |
| **RMSNorm** | $y = \gamma\odot\dfrac{x}{\sqrt{\operatorname{mean}(x^2) + \epsilon}}$ | 不减均值，也没有 $\beta$。计算更省，效果差不多。**Llama、DeepSeek、Qwen 等现代大模型的默认选择** |
| BatchNorm | 对每个特征，在整个 batch 内做归一化 | 图像卷积网络中很常用。大语言模型不用它，因为它依赖同一 batch 里的其他样本，而生成文本时一次只处理一个 token |

#### 归一化放在哪里：Post-norm 与 Pre-norm

$$
\text{Post-norm（2017 年原始 Transformer）：}\; h_{l+1} = \operatorname{Norm}\big(h_l + f(h_l)\big),
$$

$$
\text{Pre-norm（现代标准）：}\; h_{l+1} = h_l + f\big(\operatorname{Norm}(h_l)\big).
$$

Post-norm（{{fig-ch03-residual}}）把恒等路径也包进了 Norm 里，梯度每经过一层都要被 Norm 处理一次，那条高速公路就不再畅通。层数一深，训练就很不稳定，需要非常小心地调参。Pre-norm 只对送进 $f$ 的那一份做归一化，恒等路径保持干净。关键不在 Norm 写在 $f$ 的前面还是后面，而在它位于加号之前（分支上）还是之后（恒等路径上）。把 Norm 放在分支的输出端，即 $h_{l+1} = h_l + \operatorname{Norm}\big(f(h_l)\big)$，恒等路径同样干净，还能限制每一层往残差流里加的量；OLMo 2 用的就是这种写法（第 12 章），Gemma 2 则在分支的输入和输出两端都放了 Norm。现代大模型最常见的结构是：**Pre-norm 加残差连接，在输出层之前再加一个最终的 Norm。** 写成代码只有几行：

<figure id="fig-ch03-residual" data-svg="ch03_residual.svg">
<figcaption>普通层、Post-norm 残差与 Pre-norm 残差。绿色是残差连接提供的恒等路径</figcaption>
</figure>

```python
def rmsnorm(h, eps=1e-6):
    return h / np.sqrt((h * h).mean(axis=-1, keepdims=True) + eps)   # 为简化，省略了 γ

h = x0 @ W_in
for l in range(20):
    h = h + np.tanh(rmsnorm(h) @ W[l] + b[l])     # Pre-norm 残差块
logits = rmsnorm(h) @ W_out + b_out               # 最终 Norm
```

::: experiment
**加上残差连接和 RMSNorm。** 初始化时，各层梯度之间的差距保持在 5 倍以内（5.3e-6 到 2.6e-5）。训练设置与实验 2 相同，验证集 loss：

| 网络 | 500 步 | 3,000 步 | 6,000 步 |
|---|---|---|---|
| 20 层普通网络，std = $(5/3)/\sqrt{n}$ | 2.681 | 2.085 | 1.925 |
| **20 层，残差 + RMSNorm** | **2.452** | **1.978** | **1.826** |
:::

从第一个检查点开始就领先，最终也是最好的。20 层还只是"深"的起点，现代大模型有几十到上百层，没有残差连接和归一化根本训练不动。

### 3.3 优化器：每一步怎样走

**优化器**是根据梯度更新参数的算法。

#### SGD 的两个毛病

SGD 的更新规则是 $\theta \leftarrow \theta - \eta\, g$，其中 $g$ 是梯度，$\eta$ 是学习率。它有两个问题：

1. **所有参数共用一个步长，但不同参数的梯度大小可能差好几个数量级。** 第 1 章的 bigram 里，罕见字符 `$` 那一行的梯度只有常见字符的十万分之一左右。学习率无论怎样设，总有一部分参数步子太大，另一部分太小。
2. **小批量梯度有噪声**，参数的移动路径会来回抖动。

#### 动量

$$
m \leftarrow \beta\, m + g, \qquad \theta \leftarrow \theta - \eta\, m, \qquad \beta \text{ 通常取 } 0.9.
$$

$m$ 是近期梯度的加权累积：越新的梯度权重越大，越旧的按 $\beta$ 的幂次衰减。这种加权方式叫**指数移动平均**（EMA）。效果是：方向一致的分量会不断累积，来回抖动的分量会互相抵消。如果梯度一直不变，$m$ 最终等于 $g/(1-\beta)$，所以**实际的有效步长是 $\eta/(1-\beta)$**，$\beta = 0.9$ 时就是 10 倍。

在下面的实验 4 中，动量法用 $\eta = 0.01$ 和 SGD 用 $\eta = 0.1$，有效步长相同，结果也几乎一样。动量的优势主要体现在"山谷狭长、各方向弯曲程度差别很大"的问题上，在这个小模型上看不出来。

#### Adam：给每个参数单独定步长

$$
\begin{aligned}
m &\leftarrow \beta_1 m + (1-\beta_1)\, g && \text{梯度的 EMA，代表方向}\\
v &\leftarrow \beta_2 v + (1-\beta_2)\, g^2 && \text{梯度平方的 EMA，代表这个参数梯度的典型大小}\\
\hat m &= m/(1-\beta_1^t), \quad \hat v = v/(1-\beta_2^t) && \text{偏差修正，}t\text{ 是当前步数}\\
\theta &\leftarrow \theta - \eta\, \hat m / (\sqrt{\hat v} + \epsilon)
\end{aligned}
$$

**关键在 $\hat m/\sqrt{\hat v}$ 这一项**（{{fig-ch03-optim}}）。 它是梯度除以梯度的典型大小，**与梯度本身的绝对尺度无关**，数值通常在 1 左右或更小。所以每个参数每一步大约都移动 $\eta$ 这么多，不管它的梯度原本是 1 还是 $10^{-5}$。这就解释了第 1 章的旁注：罕见字符那一行的梯度很小，但用 Adam 时它和常见字符走得一样快。朴素梯度下降 800 步后 loss 还在 2.566，Adam 只用 50 步就降到了 2.476。

<figure id="fig-ch03-optim" data-svg="ch03_optim.svg">
<figcaption>三种优化器在一个狭长山谷上走 40 步的路径（示意）</figcaption>
</figure>

还有一个好处：如果某个参数的梯度符号一会儿正一会儿负（说明那是噪声），$m$ 会被平均到接近 0，而 $v$ 不会，于是这个参数的步子自动变小。可以把 Adam 理解为按"梯度方向有多一致"来分配步长。

**偏差修正**：$m$ 和 $v$ 都从 0 开始，前几步的估计会严重偏小，除以 $(1-\beta^t)$ 可以纠正这个偏差。代入 $t = 1$：$\hat m = g$，$\hat v = g^2$，**第一步的更新量正好是 $\eta\cdot\operatorname{sign}(g)$**，即所有参数在第一步都按梯度的符号移动整整 $\eta$。讲 warmup 时会用到这一点。

**$\epsilon$ 的作用**：防止除以 0，通常取 $10^{-8}$。

::: experiment
**实验 4：优化器对比。** 一个隐藏层的网络（宽 512），batch 256，训练 5,000 步，验证集 loss：

| 优化器 | 500 步 | 5,000 步 |
|---|---|---|
| SGD，$\eta = 0.1$ | 2.534 | 2.144 |
| SGD + 动量（$\beta = 0.9$），$\eta = 0.01$ | 2.538 | 2.145 |
| **Adam，$\eta = 3\times10^{-3}$** | **2.224** | **1.890** |
:::

**代价**：每个参数要额外存 $m$ 和 $v$ 两个数。第 0 章说"每个参数 16 字节"，其中 $m$ 和 $v$ 各占 4 字节（fp32），就是这里来的。

#### 权重衰减与 AdamW

**正则化**泛指一切用来减轻过拟合的技术。**权重衰减**是其中最常用的一种：每一步都让所有权重往 0 缩一点，$\theta \leftarrow \theta - \eta\lambda\theta$。它让权重保持较小，相当于偏好更简单的函数。

在 SGD 里，权重衰减等价于在 loss 上加一项 $\frac{\lambda}{2}\lVert\theta\rVert^2$，这叫 **L2 正则**。但在 Adam 里两者并不等价：如果把 L2 项加到 loss 里，它产生的梯度 $\lambda\theta$ 会和普通梯度一样被除以 $\sqrt{\hat v}$，结果是梯度大的参数，衰减反而被削弱了，这并不是我们想要的效果。**AdamW** 把衰减放到自适应缩放的外面，直接作用在参数上：

$$
\theta \leftarrow \theta - \eta\Big(\frac{\hat m}{\sqrt{\hat v} + \epsilon} + \lambda\,\theta\Big).
$$

大模型通常取 $\lambda = 0.1$，并且一般不对偏置和归一化层的 $\gamma$ 做衰减。

**大模型的标准设置**：AdamW，$\beta_1 = 0.9$，$\beta_2 = 0.95$，$\epsilon = 10^{-8}$，权重衰减 0.1。GPT-3 和 Llama 都用这组参数。$\beta_2$ 取 0.95 而不是库里默认的 0.999，是为了让 $v$ 的"记忆"更短：梯度尺度突然变化时，$v$ 能更快跟上，大规模训练更稳定（第 12 章）。近两年还出现了 Muon 等新优化器，也放在第 12 章讲。

### 3.4 学习率调度

学习率不能从头到尾保持不变：开头太危险，结尾太粗糙。

#### 结尾：为什么要衰减

小批量梯度有噪声。学习率不变时，参数会在最低点附近一直抖动，抖动幅度和学习率成正比。把学习率调小，参数才能落到更深的位置。

证据一来自第 2 章的训练日志。学习率在第 36,000 步从 0.1 降到 0.03，在第 51,000 步降到 0.01，验证集 loss 的变化是：

| step | 30k | 40k | 50k | 60k |
|---|---|---|---|---|
| 验证集 loss | 1.798 | 1.748 | 1.738 | 1.727 |

每次降学习率之后，loss 都有一段明显的下降。证据二来自下面的实验 5：同样用 Adam、峰值学习率都是 $3\times10^{-3}$，恒定学习率最终是 1.890，加上 warmup 和 cosine 衰减后是 1.780。

**cosine 衰减**是最常用的衰减方式：

$$
\eta(t) = \eta_{\min} + (\eta_{\text{peak}} - \eta_{\min})\cdot\tfrac{1}{2}\big(1 + \cos(\pi\cdot\text{训练进度})\big),
$$

训练进度从 0 走到 1，学习率从峰值沿余弦曲线平滑下降到 $\eta_{\min}$，$\eta_{\min}$ 通常取峰值的 10%。GPT-3 和 Llama 都是这样设置的。

#### 开头：为什么要 warmup

**warmup**（预热）是指在最初的若干步里，让学习率从 0 线性增加到峰值。

为什么开头特别危险？前面算过，Adam 第一步对**每个参数**都移动整整 $\eta\cdot\operatorname{sign}(g)$。几十万个参数同时朝各自的方向迈出一整步，而此时 $v$ 只基于一两个 batch 估计出来，并不可靠。网络很容易被一下子推进一个坏区域，比如 tanh 大面积饱和、logits 变得巨大，之后再也回不来。

::: experiment
**实验 5：学习率调度。** 一个隐藏层的网络，Adam，训练 5,000 步，验证集 loss：

| 设置 | 第 100 步 | 第 5,000 步 |
|---|---|---|
| 恒定 $3\times10^{-3}$ | — | 1.890 |
| warmup 250 步 + cosine，峰值 $3\times10^{-3}$ | — | **1.780** |
| 恒定 $3\times10^{-2}$（偏高），无 warmup | 3.878（已经坏了） | 3.992（比 unigram 还差，再也没恢复） |
| warmup 250 步 + cosine，峰值 $3\times10^{-2}$ | 2.763（正常） | 2.044 |
:::

注意，有 warmup 的那一组在第 250 步之后也到达了同样的峰值 $3\times10^{-2}$，却没有出问题。这说明**危险主要集中在训练刚开始的那一段**。warmup 让网络先走到一个比较稳定的区域，同时让 $v$ 积累起可靠的估计，然后再承受大的学习率。

#### WSD 调度

**WSD**（Warmup–Stable–Decay，三种调度的对比见{{fig-ch03-sched}}）：先 warmup，然后在大部分训练时间里保持恒定学习率，最后用一小段时间快速衰减。它的好处是不必提前确定总步数：可以从平台期的任意一个检查点分出一支，单独做衰减，得到一个可以评测的模型。近年用得越来越多，DeepSeek-V3 用的也是"长平台加末段衰减"的调度（第 11 章）。

</figure>

**峰值学习率是最重要的超参数。** 太高会训练崩溃，就像上面的 $3\times10^{-2}$；太低又学得很慢。实践中先在小模型上扫一遍来确定，它随模型规模变化的规律放在第 11 章。

### 3.5 batch size、梯度累积与梯度裁剪

#### batch size

batch 越大，梯度估计越准，噪声的标准差大约按 $1/\sqrt{B}$ 下降，但每一步的计算量也越大。可以从两个角度来看。

**硬件角度**：GPU 的强项是并行计算。在硬件被占满之前，一次处理 512 个样本和一次处理 32 个样本，耗时差不多。即使在实验所用的 CPU 上，处理同样的 64 万个样本，$B = 32$ 用了 26 秒，$B = 2048$ 只用了 5 秒。

::: experiment
**实验 6：batch size。** 一个隐藏层的网络，固定总共处理 64 万个训练样本，Adam，学习率固定为 $3\times10^{-3}$：

| $B$ | 步数 | 验证集 loss |
|---|---|---|
| 32 | 20,000 | 2.206 |
| 128 | 5,000 | 2.010 |
| **512** | 1,250 | **1.943** |
| 2048 | 312 | 2.036 |
:::

- **batch 太小**：每一步的噪声太大，对这么大的噪声来说，$3\times10^{-3}$ 的学习率偏高。
- **batch 太大**：更新步数太少。batch 超过某个值之后，把 batch 翻倍已经不能让所需步数减半，多出来的数据就浪费了。这个分界点叫**临界 batch size**，它会随着训练推进、loss 降低而变大（第 11 章）。

注意，这个实验固定了学习率。实践中换 batch 时通常要重新调学习率：batch 越大，噪声越小，一般可以用更大的学习率。SGD 的经验规则是学习率与 $B$ 成正比（线性缩放），Adam 则更接近与 $\sqrt{B}$ 成正比，而且这些规则只在临界 batch size 以下成立。

这也是为什么大模型有时会在训练中途调大 batch。大模型的 batch size 以 **token 数**计算，等于序列条数乘以序列长度。GPT-3 用的是 320 万 token；Llama 3 405B 从 400 万 token 开始，之后增加到 800 万，再到 1,600 万。

#### 梯度累积

梯度累积和下面的梯度裁剪见{{fig-ch03-accum}}。

想要的 batch 太大、显存放不下怎么办？把它拆成 $k$ 个小份（称为 **micro-batch**），每份各做一次前向和反向，把梯度加起来，然后统一更新一次参数。只要 loss 是对样本求平均的，这样做在数学上就**等价于**用一个大 batch。大模型训练都会这样做。

#### 梯度裁剪

```python
norm = np.sqrt(sum((g ** 2).sum() for g in grads))   # 全局梯度范数：所有梯度元素的平方和再开根号
if norm > 1.0:
    grads = [g * (1.0 / norm) for g in grads]        # 方向不变，长度截到 1.0
```

偶尔会有一个"奇怪"的 batch 产生巨大的梯度，一步就可能把模型推坏，这是 **loss spike**（loss 突然飙升）的来源之一（第 12 章）。梯度裁剪给每一步的步长设了一个上限。大模型普遍把阈值设为 1.0。

### 3.6 汇总：现代大模型训练的默认配方

| 环节 | 常见默认值 | 原因 |
|---|---|---|
| 初始化 | 权重约为 $\mathcal{N}(0, 0.02^2)$；残差分支的输出层再缩小；输出层要小 | 3.1：信号稳定，初始 loss 约为 $\ln V$ |
| 结构 | Pre-norm 残差连接 + RMSNorm + 输出前的最终 Norm | 3.2：梯度高速公路，各层尺度稳定 |
| 优化器 | AdamW，$\beta = (0.9, 0.95)$，$\epsilon = 10^{-8}$，权重衰减 0.1 | 3.3：每个参数自适应步长，衰减与自适应缩放解耦 |
| 学习率 | warmup（几百到几千步）+ cosine 衰减到约 10%，或者 WSD | 3.4：开头防止崩溃，结尾充分收敛 |
| batch | 几百万 token，用梯度累积实现 | 3.5：在硬件效率与数据效率之间取得平衡 |
| 梯度裁剪 | 全局范数 1.0 | 3.5：防止个别 batch 造成破坏 |

这些是公认的稳妥起点。真正的大规模训练会在此基础上，用小模型实验把具体数值调准（第 11、12 章）。

**训练前后的检查清单**：

1. 初始 loss 是否约等于 $\ln V$？
2. 各层的激活值和梯度，尺度是否稳定？
3. 训练 loss 下降了吗？训练集和验证集之间的差距有多大？
4. 有没有出现 loss spike？

::: keypoints
1. 初始化要让前向的激活值和反向的梯度都保持尺度：标准差约为 增益$/\sqrt{\text{fan\_in}}$，tanh 的增益是 $5/3$，ReLU 的是 $\sqrt2$。输出层要小，使初始 loss 约为 $\ln V$。
2. 残差连接让每层只做修正，恒等路径保证梯度能直达各层；归一化让各层输入的尺度保持稳定。现代标准结构是 Pre-norm + RMSNorm。
3. Adam 用 $\hat m/\sqrt{\hat v}$ 让每个参数的步长与梯度的绝对大小无关；AdamW 把权重衰减与自适应缩放分开。
4. warmup 防止训练开头崩溃，衰减让训练末段更好地收敛。峰值学习率是最重要的超参数。
5. batch size 是硬件效率和数据效率之间的权衡，存在临界值。梯度累积可以突破显存限制，梯度裁剪能防止单步破坏。
:::
