## 第 7 章　现代 Transformer {#ch7 .chapter}

::: goals
- 说出现代大模型相对 GPT-2 的每一处结构改动，以及每处改动要解决什么问题；
- 推导 RoPE 为什么只编码相对位置；
- 根据一份模型配置算出参数量和推理时的缓存大小；
- 写出一个现代 Transformer block。
:::

从 2019 年的 GPT-2 到今天的 Llama 3、Qwen、DeepSeek，Transformer 的骨架没有变：仍然是 Pre-norm 残差结构，每层由注意力和 MLP 组成。变化都发生在组件上：

| 组件 | GPT-2（2019） | 现代主流 | 主要原因 |
|---|---|---|---|
| 归一化 | LayerNorm（Pre-norm） | **RMSNorm**（Pre-norm） | 更省计算，效果相当 |
| 位置编码 | 可学习的绝对位置嵌入 | **RoPE** | 只编码相对位置，也更容易扩展上下文长度 |
| MLP | GELU，隐藏层宽 $4d$，2 个矩阵 | **SwiGLU**，宽约 $\frac83 d$ 或更大，3 个矩阵 | 同样的参数量下效果更好（实验结论） |
| 注意力 | 多头注意力（MHA） | **GQA**；DeepSeek 用 **MLA** | 大幅减少推理时要缓存的数据 |
| 偏置 | 有 | 大多数去掉了 | 大模型训练更稳定 |
| 输入输出嵌入 | 共享 | 小模型共享，大模型通常不共享 | 大模型里嵌入占的参数比例很小 |
| Dropout | 0.1 | 0 | 预训练数据通常只过一遍，过拟合不是主要矛盾 |
| 稳定性措施 | 无 | 部分模型加了 QK-norm、z-loss | 防止训练中途崩溃 |
| 上下文长度 | 1,024 | 8K–128K 甚至更长 | 第 9 章 |

下面逐项展开。

### 7.1 RMSNorm

第 3 章已经讲过：RMSNorm 去掉了 LayerNorm 中"减均值"那一步和偏置 $\beta$，只除以均方根，再乘一个可学习的缩放系数 $\gamma$。它的计算量更小，大量实验表明效果与 LayerNorm 相当（Zhang 与 Sennrich，2019）。

### 7.2 RoPE：旋转位置编码

#### 绝对位置嵌入的两个问题

1. **超不出训练长度。** 如果训练时最长只见过 1,024 个位置，第 1,025 个位置根本没有对应的嵌入向量。
2. **相对距离更重要。** 对语言来说，"前面第 3 个字符"这种相对关系，通常比"第 517 号位置"这种绝对编号更有用。使用绝对位置嵌入时，同一个相对关系在每个绝对位置上都得各学一遍。

#### RoPE 的思路

RoPE（Su 等，2021）的做法是：**把 query 和 key 向量按位置旋转一个角度**，位置越靠后，转得越多。这样一来，两个向量的点积就只取决于它们的位置差。

先看二维的情况。把一个二维向量 $(q_1, q_2)$ 看成复数 $q = q_1 + \mathrm{i}\,q_2$。设位置 $m$ 的 query 旋转 $m\theta$，位置 $n$ 的 key 旋转 $n\theta$：

$$
\tilde q_m = q\,e^{\mathrm{i}m\theta}, \qquad \tilde k_n = k\,e^{\mathrm{i}n\theta}.
$$

两个二维向量的实数点积等于 $\operatorname{Re}(\tilde q_m\,\overline{\tilde k_n})$，其中上划线表示复共轭。于是

$$
\tilde q_m\cdot\tilde k_n = \operatorname{Re}\big(q\,e^{\mathrm{i}m\theta}\;\bar k\,e^{-\mathrm{i}n\theta}\big) = \operatorname{Re}\big(q\,\bar k\,e^{\mathrm{i}(m-n)\theta}\big).
$$

结果里只出现 $m - n$，与 $m$、$n$ 本身无关。直观的理解是（{{fig-ch07-rope}}）：两根指针同时多转相同的角度，它们之间的夹角不变。

<figure id="fig-ch07-rope" data-svg="ch07_rope.svg">
<figcaption>RoPE 的直观理解：两根指针同时多转相同的角度，夹角不变，点积也不变</figcaption>
</figure>

**推广到 $d_h$ 维。** 把 $d_h$ 个维度两两分组，得到 $d_h/2$ 个二维平面，每个平面使用不同的旋转频率：

$$
\theta_i = \text{base}^{-2i/d_h}, \qquad i = 0, 1, \dots, d_h/2 - 1.
$$

base 通常取 10,000，Llama 3 取了 500,000。可以把这些平面想象成钟表上的指针：高频的平面像秒针，转得快，对相邻几个位置的差别很敏感；低频的平面像时针，转得慢，负责区分很远的距离。

**RoPE 只作用于 $q$ 和 $k$，不作用于 $v$。** 它在每一层都使用，而且没有可学习的参数。

```python
def apply_rope(x, cos, sin):                 # x: (B, H, T, d_h)；cos、sin 是按"位置 × 频率"预先算好的表
    x1, x2 = x[..., 0::2], x[..., 1::2]      # 每两个维度组成一个二维平面
    return torch.stack((x1*cos - x2*sin, x1*sin + x2*cos), dim=-1).flatten(-2)   # 在每个平面上做旋转
```

::: experiment
**验证 RoPE 只依赖相对位置。** 取一对随机的 $q$ 和 $k$（$d_h = 64$，base = 10,000），放在不同的位置上计算旋转后的点积：

| 位置 $(m, n)$ | (5, 3) | (105, 103) | (3005, 3003) | (5, 1) |
|---|---|---|---|---|
| 点积 | −10.14267 | −10.14267 | −10.14262 | −7.53591 |

位置差都是 2 时，点积相同；最后一位的微小差别来自浮点数计算大角度三角函数时的舍入。位置差变成 4，点积就不同了。
:::

RoPE 还有一个好处：调整 base，或者对位置做插值，就能把模型扩展到更长的上下文，例如 YaRN 方法（第 9 章）。

### 7.3 SwiGLU

**门控**（gating）的意思是：用一路信号去逐元素地乘另一路信号，控制每个维度"放行多少"。SwiGLU 是带门控的 MLP（Shazeer，2020；数据流见{{fig-ch07-swiglu}}）：

$$
\text{普通 MLP：}\;\operatorname{FFN}(x) = \operatorname{GELU}(xW_{\text{up}})\,W_{\text{down}},
\qquad
\text{SwiGLU：}\;\operatorname{FFN}(x) = \big(\operatorname{SiLU}(xW_{\text{gate}})\odot xW_{\text{up}}\big)\,W_{\text{down}},
$$

其中 $\operatorname{SiLU}(z) = z\,\sigma(z)$，$\sigma$ 是 sigmoid 函数。SiLU 又叫 Swish。

<figure id="fig-ch07-swiglu" data-svg="ch07_swiglu.svg">
<figcaption>普通 MLP 与 SwiGLU 的数据流</figcaption>
</figure>

**参数怎样对齐**：SwiGLU 有三个矩阵，普通 MLP 只有两个。如果想保持参数量不变，隐藏层宽度 $d_{ff}$ 就要从 $4d$ 缩小到 $\frac83 d$，因为 $3\times d\times\frac83 d = 8d^2$。例如 Llama 2 7B 的 $d = 4096$，$\frac83\times4096 \approx 10{,}923$，向上取整到 256 的倍数，得到 11,008。Llama 3 8B 则把宽度加大到了 14,336（$3.5d$）。

**为什么效果更好？** 原论文的作者自己也说不清。论文里有一句很有名的话：

> We offer no explanation as to why these architectures seem to work; we attribute their success, as all else, to divine benevolence.（我们无法解释这些结构为何有效，只能把它们的成功和其他一切一样，归功于上天的仁慈。）

它的价值来自实验：在相同的计算量下，困惑度更低。

**这说明结构设计在很大程度上是经验科学。** 2021 年 Narang 等人做过一次系统的复现，发现大多数号称有改进的 Transformer 变体，换一套代码或换一个任务就不再有效。少数经得起检验的改动里，就包括 GLU 系列和 RMSNorm。所以，对任何新结构，都要先在小规模上做**消融实验**：只改动一处，其余保持不变，看结果差多少。

### 7.4 GQA：让多个头共享 K 和 V

#### 动机：推理时要缓存的数据太多

第 6 章提到过 **KV cache**：生成文本时，前面每个 token 在每一层算出的 $K$ 和 $V$ 都要保存下来，供后面的 token 做注意力时使用（第 33 章细讲）。每个 token 需要缓存的数据量是

$$
\text{每个 token 的 KV cache} = 2\,(K\text{ 和 }V) \times L \times n_{kv} \times d_h \times \text{每个数的字节数},
$$

其中 $n_{kv}$ 是 KV 头的个数。注意每头的维度 $d_h$ 是由 query 一侧决定的：$d_h = d/n_h$，而 $k$ 要和 $q$ 做点积，维度必须相同。所以 $n_{kv}\,d_h = d\cdot n_{kv}/n_h$。在 MHA 里 $n_{kv} = n_h$，这一项恒等于 $d$，头数多少都一样；只有让 $n_{kv}$ 小于 $n_h$（下面的 GQA、MQA），缓存才真正变小。第 4 章讲过，生成时的每一步都受显存带宽限制。缓存越大，每一步要读的数据就越多，能同时服务的请求也越少。

#### 三种方案

- **MHA**（多头注意力）：每个 query 头都有自己的 K、V 头，$n_{kv} = n_h$。
- **MQA**（Shazeer，2019）：所有 query 头共用**一个** K/V 头，$n_{kv} = 1$。缓存极小，但效果会下降，训练也不太稳定。
- **GQA**（Ainslie 等，2023）：把 query 头分成若干组，每组共用一个 K/V 头（{{fig-ch07-gqa}}）。例如 32 个 query 头配 8 个 KV 头，每个 KV 头服务 4 个 query 头。论文结果显示，GQA 的效果接近 MHA，推理速度接近 MQA。

代码改动只有两处：K 和 V 的投影矩阵变窄；做注意力之前，把每个 KV 头复制 $g = n_h/n_{kv}$ 份。

```python
self.wk = nn.Linear(d, n_kv_heads * d_h, bias=False)                  # KV 头比 Q 头少
k, v = k.repeat_interleave(g, dim=1), v.repeat_interleave(g, dim=1)   # 每个 KV 头复制 g 份，供 g 个 Q 头使用
```

**计算：Llama 3 8B 的缓存大小。** Llama 3 8B 有 32 层，32 个 query 头，$d_h = 128$，用 BF16 存储：

| 方案 | 每个 token 的缓存 | 一条 128K token 序列的缓存 |
|---|---|---|
| MHA（32 个 KV 头） | 512 KB | 64 GB |
| **GQA（8 个 KV 头，实际采用）** | **128 KB** | **16 GB** |
| MQA（1 个 KV 头） | 16 KB | 2 GB |

<figure id="fig-ch07-gqa" data-svg="ch07_gqa.svg">
<figcaption>MHA、GQA、MQA 的区别在于几个 query 头共用一组 K/V（右侧数据同上表）</figcaption>
</figure>

Llama 2 70B、Llama 3 的各个尺寸都使用 8 个 KV 头。

DeepSeek 走得更远，使用了 **MLA**（multi-head latent attention，多头潜在注意力）：把 K 和 V 压缩成一个低维向量来缓存。DeepSeek-V3 每层每个 token 只缓存 576 个数，61 层合计约 70 KB/token，而它是一个 6,710 亿参数的模型。原理放在第 9 章。

**GQA 能省推理成本，却几乎不影响训练成本**：训练时不需要保存 KV cache，而 K、V 投影只占总计算量的一小部分。

### 7.5 其他改动

- **去掉偏置。** PaLM 的论文报告，线性层和归一化层都不加偏置，大模型训练会更稳定。Llama 系列沿用了这个做法。也有例外：Qwen2 在 QKV 投影上保留了偏置。
- **嵌入是否共享。** 小模型（如 Llama 3.2 的 1B、3B）让输入嵌入和输出层共享同一个矩阵，以节省参数；大模型（如 Llama 3 8B、70B）不共享，让两者各自学习。原因见第 5 章：模型越大，嵌入在总参数中的占比越小。
- **去掉 dropout。** dropout 是在训练时随机把一部分激活值置零，用来减轻过拟合。预训练的数据量极大，通常只过一遍，模型几乎不会把具体样本背下来，所以 dropout 设为 0。
- **QK-norm。** 在计算 $q\cdot k$ 之前，先对每个头的 $q$ 和 $k$ 分别做 RMSNorm，防止注意力分数在训练过程中越变越大。分数过大会导致 softmax 饱和，甚至让 loss 突然暴涨。OLMo 2、Qwen3、Gemma 3 都用了它。
- **z-loss。** 对输出层 logits 的 logsumexp 值的平方加一个小惩罚，防止 logits 整体漂移。PaLM 用的系数是 $10^{-4}$。

QK-norm 和 z-loss 都属于"训练稳定性"的话题，第 12 章细讲。

### 7.6 形状超参数：$d$、$L$ 和头数怎样选

Llama 3 论文中公布的配置：

| | 8B | 70B | 405B |
|---|---|---|---|
| 层数 $L$ | 32 | 80 | 126 |
| 宽度 $d$ | 4,096 | 8,192 | 16,384 |
| Q 头 / KV 头 | 32 / 8 | 64 / 8 | 128 / 8 |
| MLP 隐藏层宽度 $d_{ff}$ | 14,336 | 28,672 | 53,248 |
| 词表 | 128,256 | 128,256 | 128,256 |
| RoPE base | 500,000 | 500,000 | 500,000 |

从中可以看出几条经验规律：

- **每个头的维度 $d_h$ 通常是 128**；
- **宽度与层数之比 $d/L$ 大约在 100 到 130 之间**；
- Kaplan 等人（2020）发现，在参数量固定的前提下，模型效果对形状不敏感，只要不极端，怎样分配都差不多。

还有一个硬件上的细节：各个维度最好取 64 或 128 的倍数，这样能对齐 Tensor Core 的计算块（第 4 章）。nanoGPT 把 GPT-2 的词表从 50,257 补齐到 50,304，训练就快了一截。

**根据配置算出 Llama 3 8B 的参数量**（{{fig-ch07-params}}）**：**

| 部分 | 计算 | 参数量 |
|---|---|---|
| 每层注意力 | $W_q, W_o$ 各 $4096\times4096$；$W_k, W_v$ 各 $4096\times1024$（8 个头 × 128 维） | 4,194 万 |
| 每层 MLP | $3\times4096\times14336$ | 1.762 亿 |
| 32 层合计 | | 69.8 亿 |
| 输入嵌入与输出层（不共享） | $2\times128256\times4096$ | 10.5 亿 |
| **总计** | | **80.3 亿** |

### 7.7 一个完整的现代 block

```python
class ModernBlock(nn.Module):
    def __init__(self, d, n_heads, n_kv_heads, hidden):
        super().__init__()
        self.norm1, self.norm2 = RMSNorm(d), RMSNorm(d)
        self.attn = GQAttention(d, n_heads, n_kv_heads)   # 线性层不带偏置；对 q、k 施加 RoPE；KV 头复制后共享
        self.mlp = SwiGLU(d, hidden)                      # W_down(SiLU(W_gate x) ⊙ W_up x)
    def forward(self, x, cos, sin):
        x = x + self.attn(self.norm1(x), cos, sin)
        return x + self.mlp(self.norm2(x))
```

把第 6 章 GPT 中的 block 换成它，去掉位置嵌入表，再把最后的 LayerNorm 换成 RMSNorm，就得到了一个 Llama 式的模型（{{fig-ch07-block}}）。完整代码见附录 C，实际运行确认过前向计算的输出形状正确。

::: keypoints
1. 现代 Transformer 的骨架与 GPT-2 相同，都是 Pre-norm 残差结构加上"注意力 + MLP"，变化都在组件上。
2. RoPE 按位置旋转 $q$ 和 $k$，让注意力分数只依赖相对位置，而且没有参数。
3. SwiGLU 是带门控的 MLP，它的价值来自实验结果。大多数结构上的"改进"都经不起复现，所以要靠消融实验来判断。
4. GQA 让多组 query 头共享 K/V 头，把推理时的缓存缩小数倍，而效果几乎不受影响。MLA 压缩得更狠。
5. 去掉偏置、去掉 dropout、加入 QK-norm 等改动，主要是为了让大规模训练更稳定、更高效。根据配置可以准确地算出参数量和 KV cache 的大小。
:::
