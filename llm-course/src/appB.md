## 附录 B　关键数字与公式速查 {#appB .chapter}

本附录扩充了第 39 章的速查表，并给出每一项出自哪一章。记号与全书一致：$N$ 是参数量，$D$ 是训练 token 数，$C$ 是计算量，$L$ 是层数，$d$ 是模型宽度，$d_h$ 是每个头的维度，$T$ 是序列长度，$b$ 是 batch 中的序列数，$V$ 是词表大小，$n$ 是参与通信的卡数，$\Psi$ 是参数个数（讲显存时用）。硬件数字均为 SXM 版、稠密运算的峰值。

### B.9 推理

| 内容 | 公式或数字 | 章 |
|-----------|------------------------------|-----|
| decode 吞吐量 | 每步耗时 $(W + BK)/\text{BW}$，吞吐量 $B\cdot\text{BW}/(W + BK)$，$B\to\infty$ 时趋于 $\text{BW}/K$ | 33 |
| 投机采样 | 以 $\min(1, p/q)$ 的概率接受；接受率 $\alpha = 1 - \mathrm{TV}(p, q)$ | 34 |
| 投机解码的收益 | 每次调用目标模型期望产生 $(1 - \alpha^{\gamma+1})/(1 - \alpha)$ 个 token | 34 |
| 量化 | INT8 几乎无损；INT4 需要分组（如每 128 个一组）或 GPTQ、AWQ | 34 |
