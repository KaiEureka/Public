# 110.大模型（LLMs）幻觉（分类与缓解）/ 幻觉类别定义（事实冲突、虚构捏造、忠诚度偏离）

#### 在 LLM 语境下，什么是“幻觉”？给出一个全面的定义。

在 LLM 语境下，幻觉是指模型生成的文本内容与事实世界、用户提供的上下文，或其自身的逻辑前提之间存在不一致、无根据或完全捏造的现象。幻觉不是模型的输出出现了语法或拼写错误，而是模型“一本正经地胡说八道”，即生成的内容具有高度的语言流畅性和自信度，但其语义内容是虚假的。

更全面地理解幻觉，需要把握以下三个核心维度：

- 与外部事实的冲突：模型声称“爱因斯坦在1945年获得了诺贝尔物理学奖”，而真实历史是他在1922年获奖。这是最常见的对客观事实的偏离。

- 对用户上下文的背叛：在 RAG 场景中，用户明确提供了一段文本，要求模型基于该文本作答。如果模型无视这段文本，自行编造了其中不存在的信息，即使这个信息碰巧是真实的，也构成幻觉。这里的“真实性”基准是用户提供的上下文。

- 内部逻辑的不自洽：模型在生成的长篇回答中，前后表述自相矛盾。例如，前文说“该产品售价为100元”，后文在汇总时又说“总价200元”，而中间只增加了一个50元的配件。这种逻辑链条的断裂也属于幻觉。

因此，幻觉的本质是生成语义与约束条件（世界知识、用户指令、逻辑规则）之间的偏差。它是语言模型统计本质的固有属性，而非偶然的 bug。

#### 幻觉通常可以分为哪几类？例如事实性幻觉和忠实性幻觉，解释其区别。

学术界通常从约束条件的角度将幻觉分为两大类：事实性幻觉和忠实性幻觉。

1. 事实性幻觉

这是指模型生成的内容与外部世界可验证的事实、常识或公认知识相悖。评估基准是独立于当前对话的客观世界知识。

- 例子：错误地回答“法国首都是里昂”。

- 根源：预训练数据中的错误、过时信息被模型记忆，或模型在生成时未能正确检索到内部知识。

2. 忠实性幻觉

这是指模型生成的内容偏离或违反了用户提供的上下文、特定指令或任务目标。评估基准是用户给定的输入文本或指令。

- 例子：用户要求摘要一篇关于“苹果公司财报”的文章，但模型摘要中却出现了“新款 iPhone 将于9月发布”的信息，而原文根本未提及此事。即使这个新信息碰巧是真的，它也构成了对用户指令的“不忠”。

- 根源：模型未能聚焦于给定的上下文，或过度依赖自身的参数化知识，意图“补充”或“延展”用户提供的信息。

核心区别：事实性幻觉挑战的是“世界的真相”，而忠实性幻觉挑战的是“用户给的原件”。一个回答可以没有事实性幻觉，但有忠实性幻觉（编造了上下文外的好信息）；反之亦然。在 RAG、摘要、翻译等任务中，防范忠实性幻觉是首要目标。

#### 什么是事实冲突？给出一个模型输出与已知事实矛盾的例子。

事实冲突是事实性幻觉最直接的体现。它指的是模型生成的陈述，在真实、可验证的世界知识中，被证明是错误的。这种错误不是观点上的分歧，而是对客观存在的信息的歪曲。

本质：事实冲突直接证明了模型的参数化知识库中存在错误、过时或不完整的记忆，并且模型在生成时错误地“信任”了这些记忆。

例子：

假设我们向 LLM 提问：“请介绍一下阿尔伯特·爱因斯坦获得诺贝尔物理学奖的情况。”

一个存在严重事实冲突的回答如下：

> “爱因斯坦因其著名的质能方程式 E=mc² 在 1921 年被授予诺贝尔物理学奖。颁奖典礼在斯德哥尔摩隆重举行，他在演讲中详细阐述了这一公式的发现过程。”
>

这个回答包含了多处事实冲突：

- 获奖年份冲突：爱因斯坦获得诺贝尔物理学奖的年份是1922年，而不是 1921 年（1921年的奖项在1922年才正式颁发并补授）。

- 获奖理由冲突：他获奖的理由是对光电效应的发现和理论解释，而不是因为相对论或质能方程式 E=mc²。

这个例子清晰地展示了模型是如何将一个看似合理的叙述（“最著名的公式”理应获奖）与错误的事实记忆（年份错误）和事实虚构（理由错误）缝合在一起，生成一段极具欺骗性的文本。

#### 虚构捏造具体指什么？为什么 LLM 会生成不存在的人物、事件或引用？

虚构捏造是幻觉中最极端、最危险的表现形式。它指的是模型完全无中生有地生成在现实世界中根本不存在的实体、事件、文献或数据。这不仅仅是搞错已有事物的属性，而是凭空创造一个全新的、虚假的“事实”。

具体表现

- 捏造人物：生成一个完全不存在的历史人物，并赋予其详细的生平。

- 捏造事件：描述一场从未发生过的会议、灾难或科研成果。

- 捏造引用：编造一篇由真实作者发表、但完全不存在的论文标题、期刊名、甚至摘要和结论。这是学术场景下最恶劣的幻觉。

- 捏造数据：为一个论据提供一个看似精确、但完全虚构的百分比或统计数字。

为什么 LLM 会生成这些不存在的东西？

根本原因在于 LLM 的本质是一个统计语言模型，而非一个知识检索系统。它的训练目标是最大化生成文本在训练数据分布下的概率，而不是陈述事实。

1. 统计上的合理性：对于模型来说，一个编造出的、但包含了正确作者名、常见期刊名、以及合乎语法和学术风格的引用，在统计上是“合理”的。它符合模型在学习论文文本时提取的“引用模板”。模型学会的是“引用看起来像这样”，而不是“这个特定的引用必须真实存在”。

2. 自回归生成的错误累积：当模型开始生成一个事实性陈述时，如果第一步就产生了微小的偏差，后续的每一步生成都会基于这个错误的“前提”继续发展，从而滚雪球般地生成一个逻辑自洽但完全虚构的完整故事。

3. 知识压缩的损失：模型参数是对海量训练数据的有损压缩。它无法记住所有细节，在信息不足时，会依靠统计模式进行“脑补”，这个脑补过程就是虚构捏造的温床。

#### 什么是忠诚度偏离？在摘要或 RAG 任务中如何体现？

忠诚度偏离是忠实性幻觉的核心表现形式。它专指模型生成的文本未能真实、准确地反映其输入源（用户提供的文档或上下文）的内容。无论模型输出的信息在其他地方是否正确，只要它不是输入源的忠实再现或合乎逻辑的推理，就构成了忠诚度偏离。

在摘要任务中的体现

用户要求模型为一篇关于“公司A发布新产品B”的新闻稿写摘要。

- 信息添加：模型在摘要中补充道：“该产品预计将大幅提升公司A在C市场的份额。” 但原文并未提及任何市场预测。这属于外部信息入侵，是严重的忠诚度偏离。

- 信息扭曲：原文强调“新产品B的续航时间比前代产品提升了 15%”，而模型摘要写成“新产品B的续航时间长达 20 小时，远超同类”。虽然大意看似相近，但引用了原文没有的绝对数值，并添加了主观比较，扭曲了原意。

在 RAG 任务中的体现

用户提问“公司去年的净利润是多少？”，系统检索到包含相关财务数据的文档并提交给模型。

- 错误综合：模型生成的答案将文档中的“毛利润”数字当成了“净利润”数字来回答，导致答案出错。它没有忠实于文档对这两个术语的定义和区分。

- 忽略上下文：文档中明确写道“该数据未经审计”。模型在回答时，完全不提这个重要的限定条件，给用户传递了一个错误的确定性。这也是对源文档信息的背叛。

忠诚度偏离的核心在于：模型回答与输入源之间的语义鸿沟。在 RAG 和摘要等任务中，防范这种偏离是确保系统可靠性的基石。

#### 幻觉与模型的知识截止日期有何关系？过时知识算不算幻觉？

模型的知识截止日期与其幻觉行为有着密切而复杂的关系。过时知识不完全等同于幻觉，但在特定条件下，它可以并且经常导致幻觉。

过时知识本身的属性

如果用户的问题精确地处于模型的知识截止日期之前，那么模型基于其过时但正确的知识给出的回答，不应被视为幻觉。例如，对于一个知识截止于 2023 年底的模型，用户问“2022年世界杯冠军是谁？”，模型回答“阿根廷”是完全正确的，尽管这个信息是“过时”的。

过时知识如何引发幻觉

当用户的问题涉及到知识截止日期之后发生的事件时，模型的行为就会出现问题：

1. 导致事实冲突：用户问“2024年诺贝尔物理学奖得主是谁？”。模型的知识截止在 2023 年，它不可能知道真实答案。如果它直接回答“是某某某”，那么这个答案就是纯粹编造的，构成了事实性幻觉。

2. 导致虚构捏造：模型为了满足用户的提问，可能会基于其截止日期前的趋势进行“外推”和“脑补”，捏造出一个听起来很合理的虚假事件或数据。

3. “诚实的无知” vs “自信的瞎说”：一个经过良好对齐的模型，在遇到超出其知识范围的问题时，应该能够认识到自己的局限，回答“我不知道”。而幻觉的产生，正是模型未能识别并承认自身知识边界的结果。它错误地用统计模式去填补了知识空白。

因此，过时知识是幻觉产生的重要催化剂。它划定了模型内部可靠知识的边界，任何对此边界的无意识越界，都极易落入幻觉的陷阱。

#### 分析预训练数据中错误信息如何导致模型产生幻觉。

预训练数据是 LLM 世界观的唯一来源。如果这个源头被污染，模型就会不可避免地学到错误、偏见和不存在的知识，从而在生成时忠实地复现这些错误。

错误信息的类型与污染机制

1. 事实性错误：互联网文本中充斥着大量的错误信息，包括过时的新闻、被证伪的科学研究、错误的百科词条、以及各种都市传说。模型在海量数据中学习时，无法从统计上辨别真伪，它只能学会“很多人这样说”，并将其作为知识编码进参数。当被问及相关问题时，模型就会以高置信度输出这些被污染的知识。

2. 偏见与刻板印象：数据中隐含的社会、文化、性别、种族等偏见，会被模型毫无保留地学习和放大。这虽然不一定构成事实性错误，但会形成一种系统性的、有害的认知偏差，属于广义上的“世界观幻觉”。

3. 逻辑谬误与不实推理：互联网上存在大量讨论、辩论和科普文章，其中不乏逻辑谬误、不严谨的因果推断和以讹传讹的“常识”。模型在学习语言模式的同时，也内化了这些错误的推理模式。这会导致模型在生成回答时，写出语法流畅、看似合理但逻辑推理链完全是错的文本。

4. 信息抽取与拼接带来的新幻觉：预训练数据中常存在不同语境信息的并置。模型在学习中可能错误地将这些信息关联起来。例如，在一篇小说中，人物 A 和人物 B 是夫妻。模型可能会“记住”这个虚构关系，并在回答关于真实人物 A 的问题时，错误地引入人物 B。

根本挑战：当前的预训练范式还无法在大规模数据上实现精细的事实核查和真伪标注。模型就像一个在充满谣言、偏见和虚构作品的图书馆里自学成才的孩子，它的知识自然也就充满了这些烙印。因此，预训练数据中的错误信息是幻觉现象的根本源头之一。

#### 为什么解码策略（如温度、Top-p）会影响幻觉率？从不确定性角度解释。

解码策略控制着模型如何从预测的概率分布中选择下一个词元，它直接决定了模型是选择“最安全、最确定”的路径，还是“更冒险、更有创造性”的路径。这种选择深刻地影响了幻觉的产生。

从不确定性角度的解释

LLM 在生成每个词元时，都会产生一个覆盖整个词表的概率分布。这个分布本身蕴含了模型对当前位置的“确定/不确定”状态。

- 低温度 / 低 Top-p / 贪心搜索：这些策略强制模型总是选择概率最高的词元（或最高概率的集合）。这使得模型行为变得过度自信和僵化。即使当前最高概率的词元指向一个错误的方向（例如，即将开始编造一个幻觉），模型也会毫不犹豫地走下去，因为它被剥夺了选择其他可能路径的“权利”。此时，模型的不确定性没有被表达出来，而是被强行压制了。

- 高温度 / 高 Top-p：这些策略通过拉平概率分布，允许模型从概率较低的“长尾”中采样。适度的温度可以引入有益的随机性，帮助模型跳出“最可能但却是错误”的路径，有时反而能减少某种类型的幻觉。但过高的温度会使模型开始选择与上下文语义相去甚远、概率极低的词元。这相当于人为地制造了极高的不确定性，导致输出变得随机、不连贯，从而产生大量无意义的、事实混乱的幻觉。它让模型从“自信的专家”变成了“语无伦次的疯子”。

关键点：幻觉的风险在模型的不确定性处于中间地带时最高。模型对某个陈述的预测概率既不是确信无疑（那通常是正确的），也不是完全随机，而是在几个可能的答案间摇摆。此时，解码策略的选择就像一个开关，决定了模型是走向事实，还是滑向幻觉。一个经过良好校准的模型，其高预测概率往往与事实正确性呈正相关。因此，在需要事实准确性的任务中，使用较低的温度是减少幻觉的通用做法。

#### 有哪些训练阶段的幻觉缓解方法？如事实性强化学习、对比学习等。

在训练阶段从根源上缓解幻觉，是构建更可靠 LLM 的关键路径。主要方法集中在优化数据质量和改进训练目标两方面。

1. 基于数据层面的优化

- 高质量预训练数据筛选：使用分类器、困惑度过滤、基于规则和模型的清洗，尽可能移除预训练语料中的错误、有害和重复信息。这是最基础也是最有效的方法之一。

- 事实性知识增强预训练：将经过人工校验的高质量知识库（如维基百科）作为重要语料，并以特定方式（如实体掩码）进行预训练，强化模型对事实性知识的掌握。

2. 基于微调与对齐的方法

- 事实性强化学习 (Factuality RLHF)：这是当前最主流的方法。它不仅让人类标注员评估回答的有用性，还专门评估其事实准确性。收集对“事实正确”回答的偏好数据，通过 RLHF 或 DPO 训练模型，使其倾向于生成忠实于源信息、不编造事实的回答。

- 对比学习：构造正例（正确、事实性的回答）和负例（包含幻觉的回答）。训练模型在表示空间中拉近与正例的距离，推远与负例的距离。这能帮助模型学习区分事实和虚构的深层特征。

- 指令微调：使用大量包含“不要编造”、“基于文档回答”等指令的任务进行微调，增强模型对忠实性要求的遵循能力。

3. 基于特殊训练目标的方法

- 损失函数改进：设计新的训练损失，专门惩罚那些导致事实错误的生成。例如，对模型在生成错误实体时的损失给予更高的权重。

- 归因训练：训练模型在生成每一个事实性陈述时，都要（或能够在内心）将其归因到特定的训练数据来源或上下文。这强制模型建立“言之有据”的内部机制。

- 自我反思训练：训练模型在生成回答后，进行自我检查，并修正潜在的幻觉。这种“生成-反思-修正”的循环可以作为训练过程的一部分。

这些训练阶段的改进，旨在从模型的“世界观”和“行为准则”层面对其进行根本性重塑，使其从一开始就更倾向于真实和忠实。

#### RAG 是如何缓解幻觉的？它能解决所有类型的幻觉吗？

RAG 是目前在推理阶段缓解幻觉最有效、应用最广的技术框架。它的核心思想是将 LLM 从一个“闭卷考试者”转变为一个“开卷考试者”。

RAG 如何缓解幻觉

1. 用外部知识锚定事实：RAG 通过检索最新的、来自可信文档库的信息，作为 LLM 生成回答的上下文。这相当于为模型提供了一个即时的、高保真的“工作记忆”，直接覆盖了其内部可能过时、错误或缺失的参数化知识。强制模型基于这些检索到的文档作答，可以极大地减少事实性幻觉。

2. 提供证据来源，增强可信度：检索到的文档片段可以直接作为答案的引证。这不仅让用户能够验证信息，也反向约束了模型——它必须为其陈述找到文档依据，否则就更容易露出破绽。这在防范虚构捏造上尤为有效。

3. 将模型角色从“记忆者”转变为“推理者”：模型不再需要依赖自己不可靠的记忆，而是专注于理解和综合给定的材料。它被要求成为一个忠实的“信息处理者”，而不是一个全知但可能出错的“知识库”。

RAG 的局限性：它不能解决所有类型的幻觉

RAG 并非万能，它带来了新的挑战，且无法解决某些深层的幻觉。

- 无法解决忠实性幻觉（RAG 特有的）：RAG 的核心假设是“检索到的文档相关且准确”。但如果检索本身失败，带回了不相关或错误的文档，模型基于这些“垃圾”文档生成的回答，依然是错误的。更重要的是，模型可能会无视检索到的正确文档，依然我行我素地编造，或者对文档内容进行错误的扭曲和综合。这属于严重的忠诚度偏离。

- 无法解决内部逻辑不自洽的幻觉：即使给出了完美的事实，模型在进行多步推理时，依然可能犯逻辑错误，导致前后矛盾的结论。

- 解决不了来自用户指令本身的幻觉：如果用户的指令就包含错误前提，RAG 无法纠正这个前提。

- 不适用于所有任务：对于完全不需要外部知识、纯粹依赖模型内部能力的创意写作任务，RAG 并不适用。

因此，RAG 极大地提升了 LLM 的事实可靠性，但它将问题从“模型的知识不准”转移到了“检索+模型是否忠实于检索结果”。它是一个强大的工具，但必须与其他技术（如输出校验、自我反思）结合，才能构建真正鲁棒的抗幻觉系统。

#### 自我反思或 SelfCheckGPT 如何检测和减少幻觉？

自我反思和 SelfCheckGPT 是两种利用模型自身能力来检测和减少幻觉的先进方法，它们的核心思想是“以子之矛，攻子之盾”——通过分析模型自身的生成行为来识别潜在的虚假信息。

SelfCheckGPT：基于自洽性的无源幻觉检测

SelfCheckGPT 是一种不需要任何外部知识库的幻觉检测方法，其核心理念是：如果一个模型对某个事实不确定，那么它在多次独立采样中对该事实的表述会不一致；反之，如果模型对某个事实非常自信，那么它在多次采样中的表述会高度一致。

1. 多样本采样：对同一个用户提问，让模型以较高的温度独立生成多个回答（例如 5 到 10 个）。

2. 信息一致性评估：将待评估的主回答中的每一个原子事实（如“爱因斯坦出生于1879年”），与其余所有采样回答进行比对。比对可以通过多种方式进行：
  - 基于 NLI 的方法：判断其他回答是否蕴含（entail）了这个原子事实。
  - 基于问答的方法：根据该原子事实生成问题，看其他回答如何回答这个问题，再与原子事实比对。
  - 基于 BERTScore 的方法：计算该原子事实与其他回答的语义相似度。

3. 幻觉判定：如果一个原子事实在多次采样中得到的支持度很低（即其他回答很少提及或与之矛盾），那么它很可能是一个幻觉。反之，如果所有回答都一致地支持这个事实，那么它很可能是正确的。

SelfCheckGPT 巧妙地将“不确定性”转化为了检测幻觉的信号，它在开放式对话等缺乏外部知识库的场景下尤为有用。

自我反思：让模型成为自己的批评家

自我反思则要求模型在生成回答后，对自己输出的内容进行事后审查，识别出潜在的错误或无法验证的陈述，并进行修正。

1. 生成回答：模型正常生成一个初步回答。

2. 注入反思提示：系统向模型发送一个专门的反思指令，例如：“请仔细检查你刚才的回答。是否存在任何事实性错误、逻辑矛盾或缺乏依据的陈述？如果有，请指出并修正。”

3. 自我审查与修正：模型（或一个独立的、更强大的反思模型）阅读自己生成的内容，扮演一个严格的批评家。它可能会发现：
  - “我声称该产品在 2023 年发布，但我并不确定这个年份，我应该删除这个具体年份。”
  - “我在回答中引用了一篇论文，但我无法确认这篇论文是否真实存在，我应该删除这个引用。”

4. 输出修正后的回答：模型根据审查结果，输出一个修正后的、更可靠的回答。

两者如何减少幻觉

- SelfCheckGPT 主要通过过滤来减少幻觉：它像一个质检员，在多个草稿中找出最可靠的信息，或标记出不可靠的部分。

- 自我反思 则通过修正来减少幻觉：它像一个负责任的作者，在交稿前自己通读一遍，把不靠谱的地方改掉。

这些方法的价值在于它们不依赖外部工具，而是挖掘了模型内部的“自我意识”和“不确定性”，为构建更诚实的 AI 系统提供了新的思路。

#### 如何利用 NLI 模型来评估生成文本的忠实度？

NLI 模型是评估生成文本忠实度（即答案是否忠实于给定的上下文）的强大工具。它将忠实度评估转化为了一个成熟的、可自动化的语义判断任务。

NLI 模型的工作原理

NLI 模型被训练来判断两个文本片段之间的逻辑关系。给定一个“前提”和一个“假设”，它会输出三种标签之一：

- 蕴含：假设的内容可以从前提中逻辑推导出来。

- 矛盾：假设的内容与前提的内容相悖。

- 中立：前提没有提供足够的信息来判断假设的真假。

如何用于忠实度评估

在 RAG 或摘要等场景中，评估流程如下：

1. 分解答案：将模型生成的答案拆解为一系列独立的、最小粒度的“原子事实”或“陈述句”。例如，“爱因斯坦于1879年出生于德国乌尔姆市”可以分解为“爱因斯坦出生于1879年”和“爱因斯坦出生于德国乌尔姆市”。

2. 逐条验证：将每一个原子事实作为“假设”，将提供给模型的原始上下文（如检索到的文档）作为“前提”，送入 NLI 模型。

3. 判定忠实度：
  - 如果 NLI 模型输出“蕴含”，说明该原子事实得到了上下文的支持，是忠实的。
  - 如果输出“矛盾”或“中立”，说明该原子事实无法从上下文中验证，很可能是一个幻觉。

4. 计算忠实度分数：最终，模型的忠实度得分 =（被判定为“蕴含”的原子事实数量）/（原子事实总数）。得分越高，表明答案越忠实于源信息。

优势与局限

NLI 模型评估忠实度的优势在于其自动化和标准化，可以快速大规模地进行评估。然而，它也有局限性：NLI 模型本身可能出错，尤其是在处理需要复杂推理或领域专有知识的情况下。因此，它最适合作为开发阶段的快速检查工具和在线监控的预警器，而在高风险场景下，仍需人工或更强大的 LLM 进行二次复核。

#### 在对话系统中，幻觉和“不确定表达”有何区别？如何让模型学会承认“不知道”？

核心区别

幻觉和不确定表达是模型面对自身知识局限时的两种截然不同的行为模式。

- 幻觉：模型在不知道正确答案的情况下，却以一种高度自信、确定的口吻，生成了一段虚假的信息。它是在“装懂”，是模型错误地填补了知识空白。
  - 特征：语气肯定，内容丰富，细节具体，但无事实依据。
  - 例子：用户问“张三院士的博士导师是谁？”，模型不知道，却生成“张三院士的博士导师是李四教授，一位著名的物理学家。”

- 不确定表达：模型意识到自己知识的局限，并诚实地表达出这种不确定性。它是在“坦诚”，是模型正确识别了自身能力的边界。
  - 特征：使用“可能”、“据我所知”、“我不确定”等措辞，或直接声明“我无法回答这个问题”。
  - 例子：用户问同样的问题，模型回答“对不起，我目前的知识库中没有关于张三院士博士导师的信息。您可以尝试查阅相关学术资料。”

如何让模型学会承认“不知道”

让模型学会“知之为知之，不知为不知”，是对齐训练中的一个核心挑战。主要方法包括：

1. 高质量的对齐训练数据：在 RLHF 或 DPO 训练中，构造大量“无法回答”的问题。对于这些问题，人类标注员将“诚实地承认不知道”的回答标记为“好”，而将“编造答案”的回答标记为“差”。通过大量这种偏好数据，模型可以学会“诚实”是一种被奖励的行为。

2. 指令微调与提示词工程：在模型训练或系统提示中明确注入行为准则，例如：“如果你不知道答案，请直接说‘我不知道’，绝对不要编造任何信息。”这为模型的行为提供了直接的指导。

3. 知识边界探测与校准：在模型训练中，使用技术来帮助模型更好地估计自身的确定性。例如，训练模型输出一个“置信度”分数，或者使用多个采样结果的一致性来作为置信度的代理。当置信度低于阈值时，触发“承认不知道”的行为。

模型产生幻觉往往不是因为“想骗人”，而是因为它在训练中被过度训练为“总是要有答案”。承认“不知道”需要模型具备一种更高级的元认知能力——对自身知识状态的准确评估。

#### 什么是“幻觉雪崩”？如何中断？

幻觉雪崩是指模型在自回归生成过程中，基于自身之前生成的一段不实信息，继续推理和生成，从而产生一连串的、连环的、放大的虚假内容。这是一种典型的错误传播现象。

发生机制

在标准的自回归生成中，模型每生成一个 Token，它就会成为上下文的一部分，用于生成下一个 Token。如果模型在某个时刻产生了一个幻觉（例如，错误地声称“A公司收购了B公司”），那么这个虚假的“事实”就被正式写入了上下文历史。在后续的生成中，模型会基于这个虚假的前提继续推理，比如它会接着生成“这次收购对市场的影响是...”，然后可能会编造出股价的虚假波动、高管的虚假评论等。就像一个谎言需要无数个谎言去掩盖，最初的幻觉就像滚雪球一样，引发一连串的、规模更大的幻觉。

如何中断幻觉雪崩

中断雪崩的关键在于事实核查的介入时机和生成过程中的自检机制。

1. 分段生成与中间验证：不一次性生成整个长篇回答，而是将生成过程分成多个阶段。在模型生成一个段落或完成一个子任务后，暂停生成，利用外部事实核查工具（如搜索引擎、知识库）或内部自我反思模型，对刚刚生成的内容进行验证。如果发现关键事实错误，立即修正并清空错误上下文，然后从修正后的状态继续生成。

2. 基于置信度的动态调整：监控模型生成每个关键事实（如实体、数字、断言）时的预测概率或熵。如果模型在生成某个关键信息时表现出高不确定性，立即触发一个自我反思步骤，或在输出中插入一个“待验证”标记。

3. 思维链的自我修正：在提示词中训练模型，在生成过程中进行“如果我刚才的假设是错误的，那么...”的备选推理。这使得模型有能力在发现逻辑矛盾时，主动回退并修正之前的错误陈述。

4. RAG 式的事实锚定：强制要求模型在做出任何重要的、可验证的事实性陈述之前，都必须先通过搜索工具获取权威信息，并将生成锚定在这些搜索结果上。这从根本上杜绝了雪崩的起点。

中断幻觉雪崩，本质上是将“一次性生成”的过程，转变为“生成-校验-修正”的多个闭环。它需要系统架构层面的支持，而不仅仅是依赖模型自身的能力。

#### 如何通过调整提示来减少幻觉？效果上限在哪里？

通过提示词工程来减少幻觉，是一种成本最低、实现最快的缓解策略。其核心思想是通过清晰、强硬的指令，为模型设定“必须实事求是”的行为框架。

有效的提示调整策略

1. 强指令约束：在系统提示中用最严厉的语言设定规则。例如：“你是由 XYZ 公司开发的可靠助手。你的所有回答都必须严格基于可靠的事实。如果你不确定某个信息的真实性，你必须诚实地说明你的不确定性，绝对不允许编造或猜测。”

2. 引用来源要求：强制要求模型为其关键陈述提供引用来源。例如：“在回答问题时，如果你引用了外部知识，请务必指明信息的出处。” 这能迫使模型进行“有据可查”的生成，减少随意编造。

3. 自我怀疑与反思提示：在提示中要求模型在生成答案后，进行一轮自我检查。例如：“在给出最终答案前，请先自我审查，检查是否有任何事实性错误或过度推测。” 这是将“自我反思”机制外化为提示指令。

4. 角色扮演与场景设定：通过设定高权威角色来约束模型行为。例如：“你是一位正在为顶级学术期刊撰稿的科学家，你的每一个陈述都必须有坚实的文献支持。” 这种角色锚定能激发模型更严谨的生成模式。

5. 输出格式约束：要求模型以结构化格式输出，例如，区分“事实”、“推测”和“待查证信息”。这种格式强制了模型在生成时进行分类思考。

效果上限在哪里

提示词工程虽然有效，但其效果存在明确的上限。它只是对模型生成行为的一种“软约束”，而不是对模型内部知识库的“硬修正”。

1. 无法纠正模型固有的错误知识：如果模型在预训练中“坚信”一个错误的事实（例如，“香蕉是蔬菜”），无论提示词多么强硬，它依然可能在回答中流露这种错误。

2. 对复杂的、隐蔽的幻觉作用有限：当模型进行多步推理时，它可能在中间步骤产生一个微妙的、不合逻辑的跳跃，最终导致一个错误的结论。这种深层推理错误很难通过简单的提示词来预防。

3. 模型可能“学会”绕过规则：就像提示注入攻击一样，模型可能只是在输出中学会了说“据我所知”或“根据可靠来源”这些套话，但其背后的生成逻辑仍然是随意的。

因此，提示词工程是减少幻觉的第一道防线，它成本低、见效快，但要构建真正可靠的系统，必须将它与其他更深层次的技术（如 RAG、自我反思、训练阶段的改进）结合起来。

#### 模型规模增大，幻觉率会下降吗？研究结论如何？

核心结论：是的，总体上，随着模型规模的增大，幻觉率呈下降趋势，但并非线性下降，也远未被消除。这是一个被广泛验证的“规模效应”，但同样伴随着复杂的“逆规模效应”。

研究结论的主要发现

1. 总体下降趋势：大量研究表明，随着模型参数从数百万增加到数千亿，模型在 TruthfulQA 等幻觉评测基准上的表现持续提升。更大的模型在预训练中接触了更庞大、更多样的知识，能够建立更鲁棒的事实关联，其对常见幻觉的“免疫力”更强。

2. U型或逆规模效应：对于一些特定类型的幻觉，模型越大，问题反而可能越严重。这是最令人警惕的发现。例如，模型规模的增大，会增强其“编造更可信的谎言”的能力。一个大模型可能不再犯“法国首都是伦敦”这种低级错误，但它能编造出一个逻辑自洽、细节丰富、听上去极其有说服力的虚假研究案例。这使得幻觉更隐蔽、更难被检测。此外，模型规模增大也可能放大训练数据中固有的社会偏见。

3. 诚实与自信的校准：更大的模型在回答问题时，往往表现出更高的“自信度”（即预测概率更高）。但这并不意味着它们更“诚实”。研究发现，模型对错误答案的自信度也在提升，即它更“坚定地”错着。这说明模型的自我认知校准能力并没有随着规模同步提升。

4. 涌现的诚实能力：在一些复杂任务上，当模型规模超过某个阈值时，会涌现出新的能力，例如更好地理解“我不知道”的含义，或者更有效地利用上下文进行事实核查。

总结：扩大模型规模是减少幻觉的有效手段之一，但它不是一个根本的解决方案。它在解决了一些低级幻觉的同时，又引入了更高级、更隐蔽的幻觉风险。这提醒我们，不能盲目追求模型规模的无限扩张，而必须同步开发更强大的幻觉检测和缓解技术。

#### 幻觉与“知识冲突”：当检索到的信息与模型内部知识矛盾时，模型应如何选择？会产生哪些幻觉模式？

知识冲突是 RAG 系统面临的核心挑战之一。它指的是，检索到的外部文档中的信息，与 LLM 内部参数化知识相悖。此时，模型必须抉择：是相信外部“权威文件”，还是相信自己“内心的记忆”。

模型应如何选择？

在 RAG 的设定下，模型应该无条件地优先相信检索到的外部信息。这是 RAG 架构的设计前提：外部知识库是比模型内部记忆更实时、更准确、更权威的信息源。如果模型在冲突面前选择了自己的记忆，那么 RAG 就失去了其存在的价值。系统设计者需要通过强大的提示工程和模型对齐训练，强制模型遵循“外部信息优先”的原则。

会产生哪些幻觉模式？

当模型未能正确处理知识冲突时，会产生多种典型的幻觉模式：

1. 冲突忽略与内部记忆优先：模型完全无视检索到的外部文档，直接基于自己的内部知识生成答案，导致输出的信息与提供的文档相矛盾。这是最严重的忠实性幻觉。

2. 冲突混淆与信息拼凑：模型试图调和矛盾，将外部信息和内部知识进行不合逻辑的拼接，创造出一个“混合体”。例如，外部文档说“公司A的CEO是张三”，模型记忆说“公司A的CEO是李四”。它可能生成“公司A的CEO是张三，他曾接替李四担任此职”（假设张三确实接替了李四），这在事实上可能是对的，但如果原文并未提及这种接替关系，则构成了信息添加。更糟糕的情况是，它会生成一个完全混乱的、自相矛盾的叙述。

3. 冲突扭曲与错误归因：模型为了满足指令，将外部信息错误地归因或扭曲。例如，外部文档显示某个产品的价格是“100元”，但模型记忆中该产品一直卖“150元”。它可能生成“该产品在原价150元的基础上降价了50元”，而原文根本没有提到原价和降价。它用自己的知识“解释”了外部信息，但产生了偏离。

4. 过度保守与拒绝回答：这是模型过于“听话”的表现。当检测到冲突时，它放弃了整合和推理，直接回答“信息矛盾，我无法回答”。虽然在很多情况下这是诚实的表现，但有时模型需要在这些矛盾中进行分析和总结，这种过度保守会限制模型的能力。

处理知识冲突的核心，在于通过精细的指令微调和对齐训练，让模型能够在忠实于外部信息的前提下，智慧地处理矛盾，例如，明确指出矛盾所在，并基于外部信息进行有限度的推理，同时注明其不确定性。

#### 如何设计一个幻觉评估基准？需要包含哪些类型的测试样例？

设计一个好的幻觉评估基准，需要全面覆盖各种幻觉类型，并模拟真实世界的复杂场景。它应该像一份针对“谎言识别”的全面体检表。

基准需要包含的测试样例类型

1. 事实性幻觉测试集：
  - 基础事实：简单、明确的事实问题，用于测试模型是否掌握了基本的世界知识（如“水的沸点是多少度？”）。
  - 特定领域知识：覆盖多个专业领域（如历史、地理、医学、法律）的深度问题，考察模型的知识精度。
  - 时间敏感问题：针对知识截止日期之后发生的事件，考察模型是诚实地说“不知道”，还是会编造答案。
  - 反事实问题：构建与已知事实相反的假设性问题，考察模型是否会被引导产生错误陈述。

2. 忠实性幻觉测试集：
  - RAG/摘要场景：提供一段长文档，然后要求模型回答基于文档的问题或进行摘要。答案应严格基于文档，任何文档外的信息都算作幻觉。
  - 指令偏离测试：提供明确的指令（如“用100字以内回答”），考察模型的回答是否严格遵守了指令约束。
  - 逻辑一致性测试：要求模型进行多步推理，检查其推理链是否前后矛盾，最终结论是否与前提一致。

3. 虚构捏造与归因幻觉测试集：
  - 捏造引用：要求模型为一个论点提供支持性文献引用，考察其提供的论文标题、作者、期刊是否真实存在。
  - 捏造人物/事件：提出需要具体知识的问题，考察模型是否会在不知道的情况下，杜撰出看似真实的人物、地点或事件。

4. 高级幻觉与置信度测试集：
  - 不确定性表达：对模型无法知道答案的问题，考察其是否能诚实地表达不确定性，而不是给出确定但错误的回答。
  - 对抗性提示：包含试图诱导模型产生幻觉的提示词，测试其鲁棒性。

5. 多模态幻觉测试集：
  - 图文不一致：提供一张图片和一段文本描述，考察模型是否能识别出描述中的错误（例如，描述说图中是一只猫，但实际图中是一只狗）。

设计原则

- 多样性：覆盖不同领域、不同难度、不同语言。

- 平衡性：正例（要求正确回答）和反例（要求识别或避免幻觉）要均衡。

- 自动化可评分：题目应有明确的、可自动判定的答案，或采用 LLM-as-a-Judge 进行标准化评分。

- 动态更新：定期增加新题目，以防止模型过拟合于静态测试集。

一个全面的幻觉基准，是衡量所有抗幻觉技术效果的唯一客观标尺。

#### 什么是“归因幻觉”？在引用源文献时如何产生？

归因幻觉是一种非常具体且危害巨大的幻觉类型，它指的是模型生成的内容中，对信息来源（如作者、论文、网址、机构）的引用是错误的、张冠李戴的、甚至是完全捏造的。这不仅仅是内容错了，而且是为错误内容披上了一层看似可信的“权威外衣”。

在引用源文献时如何产生

1. “引用模板”的统计学习：模型在海量学术文本中学会了引用的“格式”和“语境”。它知道，在提到某个观点后，接一个“(Author, Year)”的标记是标准做法。但它常常把“格式”和“内容”学混淆了。当它需要引用时，它会从记忆中选取一个与当前话题相关的、高频率的、真实的作者名，然后随机配上一个常见的期刊名和年份，从而生成一个看起来毫无瑕疵但实际上是伪造的引用。

2. 实体的错误关联：模型可能记得“张三”是一位著名的计算机科学家，“李四”写了一篇关于深度学习的著名论文。当它需要引用一个关于深度学习的观点时，它可能会错误地将两者关联，生成“(张三, 2020)”这样一个作者正确但文献不存在的引用。

3. 为了“可信度”而进行的脑补：模型被训练为使其输出看起来可信。它“知道”一个带有引用的回答比一个没有引用的回答看起来更权威。因此，当它不确定某个信息时，它倾向于主动添加引用来增强其可信度，而这个引用本身就是虚构的。

4. 信息提取的不完整和混淆：模型在预训练时从多篇论文中提取信息。它可能记住了论文 A 的某个数据和论文 B 的某个结论，但在生成时将它们合并到了一个虚构的引用“(C, 2021)”之下。

归因幻觉的危害：它严重侵蚀了学术诚信和信息的可追溯性。用户可能会基于这些虚假的引用做出错误的决策，或将其误认为是真实存在的可靠知识。检测归因幻觉通常需要借助外部论文数据库（如 Crossref, PubMed）进行逐条验证。

#### 多模态模型中的幻觉有何特殊表现？如生成图像与文本不匹配。

多模态模型（如 GPT-4V、DALL-E 3）的幻觉比纯文本模型更为复杂和隐蔽，因为它们需要在不同模态的信息之间建立精准的对齐关系。

特殊表现类型

1. 图文不一致：这是最典型的多模态幻觉。
  - 描述与图像矛盾：给模型一张“猫在桌子上”的图片，模型却描述为“狗在椅子上”。
  - 生成图像与文本指令不符：要求生成一张“红色的汽车”，模型却生成了一辆蓝色的汽车；或者要求一个特定场景，结果图像中凭空出现了文本中未提及的物体。
  - 数量错误：要求生成“三个苹果”，却生成了五个。

2. 跨模态的虚构捏造：
  - 为图像编造不存在的内容：当被问及一张复杂图表的细节时，模型可能会“看出”一些图表中根本不存在的数据点或趋势，并用流畅的语言描述出来。
  - 凭空生成特定实体的图像：要求生成“毕加索风格的猫”，模型可能生成一种类似毕加索风格的猫的图像，但它也可能编造出一张看起来像是某幅不存在的毕加索名画的图像，并信誓旦旦地说这就是原作。

3. 逻辑违背与物理常识错误：
  - 生成图像中的物理悖论：生成的图片中，物体之间的空间关系、光影关系违背物理常识，如影子方向不一致、物体悬浮在空中。
  - 文本描述忽视视觉矛盾：对一张存在明显逻辑矛盾的图像（如一个人同时出现在两个位置），模型可能会视而不见，给出一个自洽但错误的解释。

产生原因的特殊性

多模态幻觉的根源在于不同模态的编码器和解码器，以及它们之间的对齐模块，都可能存在误差。

- 视觉编码器误读：视觉编码器未能准确识别图像中的对象、数量或关系。

- 跨模态注意力错位：模型在生成文本时，注意力错误地聚焦在了图像的背景噪点上，而忽略了主体对象。

- 生成过程中的解耦失败：在生成图像时，模型可能未能正确地将文本中描述的每个属性绑定到正确的视觉元素上。

多模态幻觉的检测和缓解更加困难，因为它需要在语义空间和视觉空间之间进行交叉验证。

#### 幻觉是否可以完全消除？为什么？

结论：在可预见的未来，基于当前自回归生成范式的 LLM，其幻觉问题不可能被完全消除。 这不是一个暂时性的技术 bug，而是由语言模型的统计本质所内生的、结构性的缺陷。

无法根除的根本原因

1. 语言的统计本质 vs 真理的客观唯一性：LLM 的目标是学习并复现训练数据的语言模式分布，而不是学习一个客观的、唯一的“世界真理模型”。一个在统计上高概率出现的陈述，不一定就是事实。由于互联网文本中存在大量错误、偏见和虚构信息，模型在学习“怎么说”的同时，无可避免地会学习到“说错的”模式。

2. 知识表示的有损压缩：模型参数是对海量训练数据的有损压缩。这个过程不可避免地会丢失细节、引入噪声、产生混淆。模型就像一个只能记住摘要的考生，当被问及细节时，它不得不依靠模糊的、泛化的模式去“脑补”，这个过程极易产生幻觉。任何压缩算法都无法保证在如此高的压缩比下做到信息的完全保真。

3. 幻想的“创意”双刃剑：模型之所以能够进行创意写作、头脑风暴、生成代码，正是因为它具备“组合”和“虚构”的能力——这些能力的本质与其产生幻觉的机制是同根同源的。一个被训练为从不偏离事实的模型，将完全丧失创造力和推理能力。我们无法在保留“有益的虚构能力”的同时，完全剔除“有害的幻觉”。

4. 评估的不可判定性：对于绝大多数开放式的、面向未来的问题，我们根本没有一个预先存在的“标准答案”去衡量模型是否产生了幻觉。判断一个前沿科学猜想是否为“幻觉”，本身就需要顶尖的科学探索。

未来的方向：从“消除”到“治理”

我们必须放弃“完全消除幻觉”这一不切实际的追求，转而建立一套系统性的幻觉治理体系。这包括：

- 源头治理：改进训练数据质量和训练方法。

- 过程治理：使用 RAG、工具调用等锚定事实。

- 输出治理：自我反思、外部事实核查、人类最终确认。

最终，我们追求的 LLM 不是一个永远不犯错的“神谕”，而是一个坦诚、可纠错、可追溯的可靠助手。其可靠性将来自于整个系统的鲁棒设计，而非单一模型的无瑕完美。
